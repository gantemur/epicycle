# Proposed development sequence

1. **Phase 0 — foundation (complete):** protect private material; inventory sources; audit SOL/CALTIB; establish architecture and unresolved conventions. No model or deployment.
2. **Phase 1 — Mars longitude in Python (complete, partial numerical validation):** read P1 IX–XI and specialist reconstructions; transcribe exact parameters and locators; define chronology/frame; implement pure geometry/evaluation; verify historical examples and independent calculations; publish versioned definitions and fixtures.
3. **Phase 2 — minimal bilingual browser atlas (implemented locally, awaiting review):** share the Mars definition and numerical fixtures; responsive SVG geometry and time controls, English | Монгол toggle, phone layout, source/parameter panel, browser/Python agreement, and `/epicycle/` build path. Deployment requires separate approval.
4. **Phase 3 — controlled comparisons:** first reproduce selected XI.11–12 table calculations and settle the comparison's time/frame protocol. Add a second historically verified Mars variant only if sourced; optional modern reference after epoch-wide error assessment of a browser-capable ephemeris. Define comparison observable and reference corrections, then add a readable two-model time-series plot with angular unwrapping.
5. **Phase 4 — catalogue expansion:** extend the Sun, Moon, and other planets body by body; add historically supported latitude and distance; then Copernican and later Ptolemaic/Alfonsine variants. Add Sun-centred displays only with their reconstruction status visible.
6. **Phase 5 — research investigations:** local high-precision JPL comparisons, fits explicitly labeled modern, sensitivity analyses, reproducible publication tables/figures, and eventually archived release/data. No fitting or publication work is authorized by Phase 0.

Gate each stage on source fidelity, time/frame documentation, and numerical validation, rather than visual plausibility.

## Current workspace sequence

Phases 4A–6B delivered the deployed clock-synchronized workspace, source-checked Sun, Mars, Jupiter and Saturn longitude constructions, a common-scale Copernican [Spatial Map](planetary-map.md), and an Angular Map for historical geocentric-longitude comparisons. Angular rings have illustrative radii, not physical distances. All managed displays have independent desktop width preferences and a single-column phone layout. Further catalogue expansion still requires sourced models and validation. See [workspace architecture](workspace-architecture.md).

Accepted presentation refinements for later work: avoid crowded Angular Map ring labels near the right edge, shorten expanded mobile settings, and make Angular Map model selectors fully registry-driven before adding more historical traditions.
