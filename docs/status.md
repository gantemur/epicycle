# Status — Phase 2 local prototype awaiting review

Git is initialized on `main`. No commit, remote, push, or deployment exists. `private/` remains ignored and outside the Vite root and build import graph.

The *Almagest* Mars longitude geometry is **source-checked, implemented, and partially numerically validated**. `data/mars-almagest-v1.json` is shared by Python and TypeScript. The browser evaluates historical positions from the geometry, draws its construction with SVG, and uses continuous Egyptian days for date controls and playback. English and Mongolian strings are centralized and the selected language is stored locally where browser storage is available. The site is configured for `/epicycle/` but exists only as a local build.

The Neugebauer Table 15 discrepancy is now decomposed in [mars-almagest.md](mars-almagest.md) and tested: `0.297′` centre interpolation, `5.913′` epicycle correction, and `0.417′` final rounding make the `6.626′` geometric versus printed-table difference at the specified rounded arguments. This is a diagnostic of different numerical procedures, not a reason to change historical parameters.

`tests/fixtures/mars-cross-language.json` is generated by the Python evaluator. TypeScript tests compare all returned coordinates, radii, angles, and distances for historical and synthetic arguments and several dates; Python tests guard the saved fixture. The browser's default Nabonassar date shows `47.660°` (unrounded `47.660458°`). The P2 rounded arguments yield `47.660439°`.

Run the commands in [README.md](../README.md). Phase 2 verification includes Python tests, TypeScript tests, a production build, and local browser checks at desktop, 360 px, and 390 px in both languages. The geometry, playback, trail toggle, example jump, and source panel were inspected. No horizontal overflow was observed at either phone width. The built `dist/` contains only HTML, CSS, and JS assets; no private paths.

Open work is scientific rather than a hidden parameter adjustment: the full XI.11–12 interpolation table remains unimplemented; local-noon Julian labels are formal calendar coordinates, not UT/TT/modern ephemeris timestamps. The UI shows one Mars longitude model, no latitude or modern true-position prediction. Phase 3 should first reproduce selected original table calculations and settle a documented comparison time/frame protocol before adding another sourced model or a modern reference.
